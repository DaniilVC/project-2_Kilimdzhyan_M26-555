## Управление таблицами

После установки пакета в терминале становится доступна команда `database`.

### Команды

`create_table <имя> <столбец1:тип> ...` | Создать таблицу (столбец `ID:int` добавляется автоматически) 

`list_tables` | Показать список всех таблиц 

`drop_table <имя>` | Удалить таблицу 

`help` | Справочная информация 

`exit` | Выход из программы 

**Поддерживаемые типы:** `int`, `str`, `bool`.

---

## CRUD-операции

После создания таблицы можно работать с данными внутри неё.

### Команды

`insert into <имя> values (<значение1>, <значение2>, ...)` | Добавить запись 

`select from <имя>` | Прочитать все записи 

`select from <имя> where <столбец> = <значение>` | Прочитать записи по условию 

`update <имя> set <столбец> = <значение> where <столбец> = <значение>` | Обновить запись 

`delete from <имя> where <столбец> = <значение>` | Удалить запись 

`info <имя>` | Вывести структуру таблицы и количество записей 

### Правила
- Столбец `ID` генерируется автоматически, указывать его не нужно.
- Команды `update` и `delete` **требуют** условие `where`.

## Пример использования

```bash
>>> database

***База данных***

>>> create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>> insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".

>>> insert into users values ("Anna", 25, true)
Запись с ID=2 успешно добавлена в таблицу "users".

>>> select from users
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei | 28  |    True   |
| 2  |  Anna  | 25  |    True   |
+----+--------+-----+-----------+

>>> select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei | 28  |    True   |
+----+--------+-----+-----------+

>>> update users set age = 29 where name = "Sergei"
Запись в таблице "users" успешно обновлена.

>>> delete from users where ID = 2
Запись успешно удалена из таблицы "users".

>>> info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 1

>>> list_tables
- users

>>> drop_table users
Таблица "users" успешно удалена.
